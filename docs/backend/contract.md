# Backend contract v1.0

Read [the master plan](../backend-plan.md) first. This is the authoritative implementation contract for all four backend owners. Values chosen here are SayLess design decisions unless linked to external documentation. Person 1 owns changes; consumers must not silently redefine them.

## 1. Browser-facing HTTP contract

`POST /api/rewrite`, request `Content-Type: application/json`, response `Content-Type: application/json`. UTF-8 JSON. Synchronous, non-streaming, no authentication cookie, no credentials in frontend code.

```json
{
  "message": "I need my teammate to finish their part",
  "tone": "professional"
}
```

Success is HTTP **200** with exactly this top-level field, containing exactly three strings in presentation order:

```json
{
  "rewrites": [
    "Could you let me know when you expect to finish your part?",
    "I wanted to check in on your section so we can stay on schedule.",
    "Can you share an update on your part of the project?"
  ]
}
```

The strings above are a test fixture, not a valid universal response. Real responses come from Gemini. Never return Gemini's `candidates` envelope, `{data: ...}`, labeled card objects, a bare array, or a different field name. Set `Cache-Control: no-store` on rewrite success and error responses. Do not echo the original message in response metadata.

## 2. Request validation and normalization

| Rule | Required behavior | Owner |
|---|---|---|
| Body | Required, one JSON object; reject malformed JSON, JSON `null`, arrays, scalars and trailing JSON values | Person 1 |
| Fields | `message` and `tone` must be strings when present; do not coerce numbers/booleans/arrays/objects into strings | Person 1 |
| Unknown keys | Ignore unknown fields for v1; they never influence the prompt or configuration | Person 1 |
| Missing/null values | Semantic validation failure; do not invoke Gemini | Person 2 |
| Message normalization | Java `String.strip()` on outer whitespace; preserve interior whitespace/newlines, quotes, emoji and punctuation | Person 2 |
| Message length | Normalized length 1–2,000 **UTF-16 code units**, inclusive (`String.length()`); blank per `isBlank()` is invalid | Person 2 |
| Tone | Exact lowercase `professional`, `casual`, `diplomatic`, `funny`; uppercase, padded, empty and unknown values are invalid; never silently default on the backend | Person 2 |
| Failure ordering | Parse/type errors first; then missing/blank/long message; then tone | Persons 1–2 |

Boundary examples: 2,000 ASCII characters pass; 2,001 fail. 1,000 supplementary emoji occupy 2,000 UTF-16 units and pass the size rule. The client currently trims before sending; server validation still applies to all callers. JSON-string escaping must preserve content. Do not HTML-escape messages before sending them to Gemini; frontend rendering already uses `textContent`.

These are message limits, not a claim that the server has a general HTTP body-size limit. Infrastructure request-size/rate controls are separate deployment concerns and are outside the local demo's required implementation.

## 3. Result rules

Person 3 extracts model JSON into `List<String>` without converting other JSON types to strings. Person 2 is the final gate before success:

1. Require a non-null list of exactly **3** non-null, nonblank strings.
2. Strip each string's outer whitespace; retain interior whitespace and line breaks.
3. Each normalized string must be at most **4,000 UTF-16 code units**. Reject excess; never truncate.
4. Require three different comparison keys: normalized string → collapse runs matching Java regex `(?U)\s+` to one ASCII space → lowercase with `Locale.ROOT`. Compare keys only; return the normalized text, not the comparison keys.
5. Return a defensive immutable copy in original order. No shared per-request state.

Any violation is `AI_INVALID_RESPONSE`. Do not pad, deduplicate into fewer cards, retry generation, strip Markdown fences to salvage invalid JSON, or insert fixture text. These structural rules cannot prove semantic distinctness or intent preservation; the manual quality matrix checks those.

## 4. Error contract

All errors generated by SayLess for the rewrite route use:

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Enter a message of 1–2000 characters and choose a supported tone."
  }
}
```

No stack trace, exception class, provider response, prompt, submitted text, API key, or configuration value appears in this payload. The message strings below are the canonical safe defaults. The existing frontend can keep its generic error initially; Person 4 may map **known codes** to friendly messages without displaying arbitrary upstream text.

| Code / enum constant | HTTP | Canonical message | Trigger |
|---|---|---|---|
| `INVALID_JSON` | 400 | Send a JSON object with message and tone as strings. | Missing body, syntax/type/trailing-value failures |
| `VALIDATION_ERROR` | 400 | Enter a message of 1–2000 characters and choose a supported tone. | Semantic input rules above |
| `UNSUPPORTED_MEDIA_TYPE` | 415 | Send the request as application/json. | Unsupported request content type |
| `METHOD_NOT_ALLOWED` | 405 | Use POST to rewrite a message. | Unsupported method on `/api/rewrite`; retain `Allow` header |
| `AI_NOT_CONFIGURED` | 503 | Rewriting is not available yet. Please try again later. | Provider explicitly disabled |
| `AI_RATE_LIMITED` | 503 | Rewriting is busy right now. Please wait and try again. | Gemini 429/quota exhaustion |
| `AI_UNAVAILABLE` | 503 | Rewriting is temporarily unavailable. Please try again later. | Provider connectivity failure, 4xx configuration/auth failures, 5xx, unexpected status |
| `AI_TIMEOUT` | 504 | Rewriting took too long. Please try again. | Gemini deadline/connection timeout |
| `AI_REFUSED` | 422 | We couldn’t rewrite that message. Try rephrasing it. | Explicit provider safety/block/refusal signal |
| `AI_INVALID_RESPONSE` | 502 | We couldn’t create three rewrite options. Please try again. | Truncated, malformed or structurally invalid provider result |
| `INTERNAL_ERROR` | 500 | Something went wrong. Please try again. | Unexpected application bug |

Gemini's 429 becomes **503** because the exhausted quota belongs to the shared provider project, not necessarily this individual visitor. Do not invent a wait duration or send an unsupported `Retry-After` value. No automatic retry.

Custom envelopes are required for the documented rewrite requests/errors. Framework-level rejected CORS, unrelated 404 routes, unacceptable `Accept` headers and container-level malformed HTTP need not use this envelope. Never let generic advice turn a rejected CORS request into successful output or expose raw provider data.

## 5. Exact shared Java types

Person 1 creates each public type in its own file under `com.sayless.contract`. Other owners import these types; do not copy them into other packages.

```java
public record RewriteRequest(String message, String tone) {}
public record RewriteResponse(java.util.List<String> rewrites) {}
public record ApiErrorResponse(ApiError error) {
    public record ApiError(String code, String message) {}
}

public enum Tone {
    PROFESSIONAL, CASUAL, DIPLOMATIC, FUNNY;
    public String wireValue();
    public static Tone fromWireValue(String value);
}

public interface RewriteService {
    java.util.List<String> rewrite(String message, String tone);
}

public interface AiRewriteClient {
    java.util.List<String> generate(String normalizedMessage, Tone tone);
}

public enum ErrorCode {
    // Exactly the constants in section 4.
    public int httpStatus();
    public String publicMessage();
}

public final class RewriteException extends RuntimeException {
    public RewriteException(ErrorCode code);
    public ErrorCode code();
}

public final class RewriteLimits {
    public static final int MAX_MESSAGE_LENGTH = 2000;
    public static final int RESULT_COUNT = 3;
    public static final int MAX_REWRITE_LENGTH = 4000;
    private RewriteLimits() {}
}
```

These snippets specify signatures; enum/class method bodies must be implemented. `Tone.fromWireValue` rejects null/unknown/padded/case-mismatched strings with `RewriteException(VALIDATION_ERROR)`. It does not normalize them. `wireValue()` returns the exact lowercase wire value. `RewriteException` carries only the safe error code/message, not provider text or a raw HTTP body. Shared interfaces expose no checked exceptions, Spring types, Gemini DTOs, or JSON nodes.

Implementation classes are fixed as `api.RewriteController`, `api.ApiExceptionHandler`, `service.DefaultRewriteService`, and `provider.GeminiRewriteClient`. Controller constructor takes `RewriteService`; service constructor takes `AiRewriteClient`. Controller calls service once and wraps its list in `RewriteResponse`. The provider's request builder/parser helpers are private to Person 3's package.

## 6. Configuration and beans

Person 1 owns property declarations and binding. Use `config.AiProperties` with `@ConfigurationProperties(prefix = "sayless.ai")`, and `config.CorsProperties` with prefix `sayless.cors`. Register them once through `config.AiConfiguration` / `config.WebConfiguration`; do not rely on uncoordinated scanning changes in the application class.

The shared `AiProperties` record components, in order, are `boolean enabled`, `String apiKey`, `String model`, `java.net.URI baseUrl`, `java.time.Duration connectTimeout`, `java.time.Duration requestTimeout`. `CorsProperties` has `java.util.List<String> allowedOrigins`. Do not generate/log `AiProperties.toString()` with the key; provide a redacted implementation or never expose it through logging/binding failures.

| Spring property | Environment variable | Checked-in default |
|---|---|---|
| `server.port` | `PORT` | `8080` |
| `sayless.ai.enabled` | `SAYLESS_AI_ENABLED` | `false` |
| `sayless.ai.api-key` | `GEMINI_API_KEY` | empty |
| `sayless.ai.model` | `GEMINI_MODEL` | `gemini-3.5-flash-lite` |
| `sayless.ai.base-url` | `GEMINI_BASE_URL` | `https://generativelanguage.googleapis.com` |
| `sayless.ai.connect-timeout` | `GEMINI_CONNECT_TIMEOUT` | `3s` |
| `sayless.ai.request-timeout` | `GEMINI_REQUEST_TIMEOUT` | `20s` |
| `sayless.cors.allowed-origins` | `SAYLESS_ALLOWED_ORIGINS` | `http://localhost:5500,http://127.0.0.1:5500` |

Use explicit `${ENV_NAME:default}` mappings in `application.properties`, keeping `spring.application.name=sayless-backend`. `.env.example` documents variables but Spring Boot is **not assumed to automatically load `.env`**. Export variables in the shell or configure them in the IDE; never commit a real key. Root/backend ignore rules must exclude local `.env` variants while allowing `.env.example`.

When disabled, `AiConfiguration` creates an `AiRewriteClient` bean that always throws `AI_NOT_CONFIGURED`. It must not return sample strings. When enabled, only `GeminiRewriteClient` is registered, via the matching property condition. Exactly one client bean is active. Enabled mode requires a nonblank key/model and a valid base URL; fail startup with a sanitized explanation if configuration is incomplete. Reject models containing URL separators/query strings. Use HTTPS for non-loopback provider URLs; allow HTTP loopback only for tests. No user request may select a provider URL, model, system prompt or credential.

Require positive timeouts with `connectTimeout <= requestTimeout <= 25s`; defaults leave room before the browser's existing 30-second timeout. Person 3 enforces a total deadline through full response-body consumption, not just receipt of headers; cancel the HTTP future on expiry. No background unbounded retries. Unit tests use shorter timeouts.

## 7. CORS and static frontend

Configure CORS once in `WebConfiguration` for `/api/**`: exact configured origins, POST and OPTIONS, `Content-Type` allowed header, no credentials, no wildcard origins. Allow the JSON preflight; verify actual error responses also carry the appropriate CORS headers. CORS is not authentication or a quota protection mechanism.

Person 1 configures Maven resources to copy only `index.html`, `styles.css`, `script.js`, `output.js`, and `mock-response.js` from `${project.basedir}/../frontend` into the build's `static/` resources with filtering off. Keep normal `src/main/resources` copying. The fixture module is required because `script.js` statically imports it even in API mode. Exclude preview/test pages. Never commit copied files under `src/main/resources/static` or `target`.

After live integration, Person 4 sets the checked-in frontend mode to `api` and keeps endpoint `/api/rewrite`. Build a JAR to refresh copied resources after frontend edits. A separately served frontend must deliberately use the absolute backend endpoint and be tested with its exact allowed origin.

## 8. Privacy, logging and scope

Messages/results stay only in request-local memory and the current page DOM. No persistence, request/response body logging, prompt logging, analytics of content, provider header logging, or raw provider exception logging. Operational logs may contain a fixed error code, status and elapsed time. Do not promise that Gemini's free service has no retention; see [the provider disclosure requirement](gemini.md#free-tier-operation-and-privacy).

The MVP is a local/controlled hackathon demo. Internet deployment is a separate decision: this unauthenticated API can consume a shared provider quota. Record that limitation rather than quietly adding accounts, captchas, Redis or a large rate-limiting subsystem in one branch.
